# NEXORA
> Cobra. Administra. Comprende. Crece.

Open-source business management and digital payments platform for Mexican SMEs. Built for Hackatón México 2026.

## Vision
Connect CoDi QR and payment links through Pey with POS, inventory, CRM and financial analytics. Grok provides read-only business insights based on verified metrics. NFC tags opening payment links are a planned option; contactless card acceptance requires a separate authorized provider.

## Planned stack
React + Vite + TypeScript, NestJS, PostgreSQL/Supabase, Pey and Grok.

## MVP
- [ ] Product catalog and POS
- [ ] Pey payment creation and verified confirmation
- [ ] Transactional sales and stock updates
- [ ] Tenant isolation and role-based authorization
- [ ] Sales and gross margin dashboard
- [ ] Read-only Grok insights
