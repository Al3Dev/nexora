# NEXORA Web
React + Vite + TypeScript demo. Run `npm install` then `npm run dev` in this directory. Use a Node.js version supported by Vite 7. `npm run build` type-checks and builds. Data is synthetic and held in memory; reload resets it. No payment, authentication, backend or Grok API is connected. `npm install` and `npm run build` verified on Node 24 (2026-11-27). Dashboard visual concept implemented with responsive CSS.
